SimpleCPU ASM to VHDL translator

With this website, you can write your assembler program (in the middle table),
using the available instructions (in the left table)
and the program will be automatically translated into VHDL (the right table),
which can be copy pasted into the SimpleASM.vhd file of the SimpleCPU project.

You can add/change/delete the available assembler instructions in the ASM2VHDL.js file to match your custom version of the SimpleCPU.

You can save your ASM program (including the available instructions) by clicking on the "Copy to clipboard" button and pasting this in a text file.
Afterward, you can reload this ASM program by selecting this file again.
